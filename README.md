# Costas_Bot — Система автоматизации и бронирования для отеля «Костас»

Коммерческий проект, разработанный для автоматизации взаимодействия с гостями отеля и интеграции модуля прямого бронирования номеров через Telegram.

## 📈 История развития проекта
Изначально бот проектировался как монолитное MVP (в один файл) для базового информирования клиентов. В процессе эксплуатации задачи бизнеса расширились, проект был масштабирован и переработан для поддержки полноценного интерактивного модуля бронирования комнат.

## 🛠 Технический стек
* **Язык:** Python 3.10+
* **Библиотека:** pyTelegramBotAPI (Telebot)
* **Логика данных:** Интеграция состояний пользователя (FSM) для пошагового бронирования, валидация дат и управление доступным фондом номеров.

## 🎯 Реализованный функционал
* **Модуль бронирования:** Пошаговый выбор дат, категории номера и подтверждение брони.
* **Информационный блок:** Интерактивное меню с услугами отеля, правилами проживания и контактами.
* **Архитектурный вызов:** Переход от монолитного скрипта к модульной структуре в процессе расширения кодовой базы.

## 🚀 Как запустить (Локально)
1. Склонируйте репозиторий.
2. Создайте локальный конфиг с переменными окружения (Токен бота, параметры БД).
3. Запустите `python main.py`.
